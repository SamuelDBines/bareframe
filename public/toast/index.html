Notifications (ephemeral): use bf-toast. It exposes role and appropriate aria-live (status / polite by default, or alert / assertive for the variant alert). For inline contextual copy or form error rollups, prefer bf-message and bf-error-summary demos.

  • variant / attributes: toast, banner, snackbar, notification.
  • type / booleans: success, warning, error, info.
  • duration (ms): auto-dismiss when > 0.
